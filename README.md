# Northstar SEO Agency Landing

High-performance Next.js (App Router) landing page for an SEO agency with:

- SSR + dynamic metadata and Open Graph
- `sitemap.xml` + `robots.txt`
- JSON-LD schemas (Organization, FAQ, Service, Review)
- Framer Motion transitions and reveal animations
- Dark mode toggle with localStorage persistence
- Subtle cursor glow interaction
- API route stub and PostgreSQL connection scaffold

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
